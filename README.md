# 聚影 TV 官方发布页

电视盒子 / Android TV 影视应用「聚影」的官方发布仓库。

## 下载最新版

前往 [Releases](https://github.com/eoow123/juying-release/releases/latest) 页面下载最新 APK（`juying-arm64.apk`）。

### 国内加速下载（实测可用）

在 Release 页 APK 链接前加镜像前缀：

- `https://ghfast.top/` + APK 链接
- `https://ghproxy.net/` + APK 链接
